# สิ่งที่ตัดสินใจแล้ว · Decisions

| วันที่ | เรื่อง | ตัดสินใจ |
|---|---|---|
| 25 พ.ย. 2569 | ระบบ | สร้างระบบใหม่แยกจากทันฝน คงฟีเจอร์เดิม และเป็นงานตีพิมพ์ |
| 25 พ.ย. 2569 | ข้อมูล | ทำโมเสกเองจากภาพ HQ รายสถานี 9 สถานี ไม่ใช้ national composite สำเร็จรูปของ TMD เป็นผลิตภัณฑ์ |
| 25 พ.ย. 2569 | AI | ไม่ใช้ AI ในระบบใช้งาน (ต้องมีข้อมูลยาวก่อน) แยกเป็นงานวิจัยอีกสาย |
| 25 พ.ย. 2569 | พยากรณ์ที่แสดง | เว็บแสดงพยากรณ์เดียว = best product ที่เลือกอัตโนมัติจากคะแนนที่เก็บไว้ (config/select.yaml) |
| 25 พ.ย. 2569 | คะแนน | เก็บคะแนนทุกพยากรณ์ แต่ไม่แสดงบนเว็บสาธารณะ |
| 25 พ.ย. 2569 | เว็บ | แยกฝั่งสาธารณะกับฝั่งผู้เชี่ยวชาญ ฝั่งสาธารณะไม่แสดงสิ่งที่ผู้ใช้ไม่ต้องใช้ วงรัศมี 240/120 km เปิด/ปิดได้ทั้งสองฝั่ง |
| 25 พ.ย. 2569 | ภาษา | ไทยและอังกฤษ |
| 25 พ.ย. 2569 | ฝนรายพื้นที่ | รายลุ่มน้ำย่อย อำเภอ และตำบล แบบเปเปอร์ทันฝน |
| 25 พ.ย. 2569 | ย้อนหลัง | ฝั่งสาธารณะมีหน้าดูฝนย้อนหลัง เทียบฝนที่ตกจริงกับพยากรณ์ที่ทำไว้ล่วงหน้า |
| 27 พ.ย. 2569 | เปิด/ปิดระบบ | มีสวิตช์ในฝั่ง admin นอกฤดูฝนปิดได้: หยุดเก็บภาพ และหน้าสาธารณะวนพยากรณ์ล่าสุดก่อนปิด สวิตช์เก็บใน `config/control.yaml` เปลี่ยนผ่าน workflow `control` |
| 27 พ.ย. 2569 | ทดลองก่อน | เปิดเก็บภาพทดลองก่อน ตรวจว่าภาพทุกสถานีเข้าคลัง ผล QC และค่าการสะท้อนที่ถอดได้เหมาะสม แล้วจึงทำรายงานวิธีการ (การถอดค่า dBZ จากภาพ การตรึงพิกัด การทำ composite) พร้อมเอกสารอ้างอิงและสมการ |
| 27 พ.ย. 2569 | ปลายทางภาพ | Google Drive ของบัญชีวิจัย 5 TB (ใช้ไป 193 GB) โฟลเดอร์ `ChaoPhraya_Radar_Archive` ผ่าน rclone scope `drive.file` ใช้ client ID มาตรฐานของ rclone ก่อน (เปลี่ยนเป็นของตัวเองถ้าเจอ rate limit) (วิธีตั้ง: SETUP_ARCHIVE.md) |
| 27 พ.ย. 2569 | ที่เก็บภาพ | ภาพดิบไม่เข้า git (ทันฝนเก็บใน git จน repo โตเกิน 1.2 GB) ส่งออกด้วย rclone ปลายทางเลือกได้ด้วยตัวแปร `ARCHIVE_REMOTE` (Google Drive หรือ Cloudflare R2) |
